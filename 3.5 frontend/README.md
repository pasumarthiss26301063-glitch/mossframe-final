# MossFrame

MossFrame is a responsive image-search interface for discovering visual inspiration from a topic or keyword. I chose a warm cream, forest-green, and clay palette to give the app a calm editorial feel instead of the usual neon or purple search aesthetic. The category chips offer quick starting ideas so visitors immediately know what they could search for. I also included a clear empty state and a responsive CSS Grid so the future image collection has a welcoming place to appear on both phones and larger screens.
